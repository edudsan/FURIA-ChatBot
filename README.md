# 🤖 Chatbot FURIA para Telegram

Um chatbot inteligente para interação com fãs da FURIA no Telegram, utilizando Active Pieces e API do Gemini, com sistema de coleta de dados dos fãs.

## 📌 Visão Geral
Chatbot desenvolvido para:
- Automatizar atendimento aos fãs no Telegram
- Coletar dados estratégicos via formulário
- Prover informações via IA generativa (Gemini)

## 🛠 Tecnologias
| Tecnologia | Descrição |
|------------|-----------|
| ![Active Pieces](https://cdn.activepieces.com/brand/logo.svg) Active Pieces | Plataforma de automação |
| ![Gemini](https://img.icons8.com/color/16/000000/google-logo.png) Gemini API | IA generativa do Google |
| ![Telegram](https://img.icons8.com/color/16/000000/telegram-app--v1.png) Telegram Bot | Integração com mensagens |
| ![Forms](https://img.icons8.com/?size=20&id=69622&format=png) Google Forms | Armazenamento de dados |

## ✨ Funcionalidades

### 📋 Formulário de Dados
```
    A[Inicia com /start] --> B[Coleta Nome]
    B --> C[Idade]
    C --> D[Localização]
    D --> E[Numero de telefone]
    E --> F[Conta do X]
    F --> G[Instagram]
    G --> H[Mapa Favorito]
    H --> I[Player que inspira a ser insano no Game]
    I --> J[Em qual round heroico você mais gritou "VAMOOOO"?]
```

## 🚀 Implementação

### 🔑 Pré-requisitos
- Conta no Active Pieces

- Token do @BotFather

- API Key do Gemini

- Google Forms

### Monitoramento e Análise

- Dados dos fãs armazenados no Google Sheets

- Métricas de uso do bot disponíveis no painel do Telegram

- Logs de conversação no Active Pieces

### Melhorias Futuras
- Integração com calendário de jogos

- Notificações automáticas sobre próximos eventos

- Sistema de fidelidade para fãs engajados

- Análise de sentimentos das interações
